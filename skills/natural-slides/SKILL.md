# natural-slides

AIが作るスライドにありがちな「細い線・余白だらけ・均等3カラム・箇条書きの羅列・ですます調の説明文」を避け、図とイラストで一目で伝わる日本語の資料を作るためのルール。どの会社・どの業種でも使えるように、ブランドに関わる値は「ブランド設定」で差し替える。

出力形式の指定がなければ、その環境で使えるスライド作成の仕組み（スライド型のアーティファクト、.pptx、HTMLなど）で作る。比率は16:9、寸法は1920×1080基準で書く。文章の自然さを上げたいときは、日本語の文章スキル（natural-japanese など）を併用する。

ここから先の色・余白・図解・コピーのルールは、どの形式でも変わらない設計。変わるのは「何で組むか」だけ。HTMLとCSSはPDFで配るときに一番自由がきく。いっぽうCanva・Googleスライド・PowerPoint（.pptx）で開いて編集してもらう資料は、HTMLで作って書き出すと必ず崩れる。編集して使ってもらう形式は、最初からその形式のネイティブな部品（テキスト枠・図形・画像）で組む。詳しくは「出力先と崩れない書き出し」を先に読む。

## 始める前に

1. **ブランド設定を決める**：メインカラー1色、ロゴ画像、会社名（またはサービス名）。メインカラーの指定がなければ、黒っぽいグレー #2F3237 を使う。ロゴがなければ位置を空けておく。紫→青のような「AIらしい色」は、ブランドが本当にその色でない限り選ばない
2. **約束を一文で書く**：「誰に、何を約束する資料か」。決まらないうちは作り始めない
3. **対比を一つ決める**：資料全体の筋になる対比（今と導入後、自分でやる場合と任せた場合、など）を決め、各ページがそこに戻るようにする
4. **各スライドの主役を1つ決める**：図解、大きな数字、イラストのどれか

## 色

メインカラーを A として、次の役割で使う。以下の「アクセント」はメインカラーのこと。指定がないときの既定値は A=#2F3237（黒っぽいグレー）で、段階色は #DDDEDD → #A0A1A2 → #5F6268 → #2F3237、淡いアクセントは #BCBDBD、アクセントの地は #EFEFEE。メインカラーが無彩色のとき、色で目を引くのは黄色のマーカーとハイライト（#E5B521）だけにする。

| 役割 | 値 |
|---|---|
| 背景 | #FCFCFA（わずかに温かい白。純白にしない） |
| カード・図の箱 | #FFFFFF |
| 箱の枠線 | #DDDBD5（強調する箱は A）、太さ6〜9px |
| 主テキスト | #3C3C3C（真っ黒にしない） |
| 副テキスト | #6B6B6B |
| 弱テキスト・ページ番号 | #9A9A9A |
| アクセント | A（ピル、見出しバー、強調の箱、大きな数字） |
| 淡いアクセント | A を背景に対して約35%の濃さにした色（図の矢印、補助の枠） |
| アクセントの地 | A を約8%の濃さにした色（比較表の自社列など） |
| 段階色 | Aの15% → Aの45% → A → Aを少し暗くした色（左から右へ濃くなる工程フロー用。文字は前の2色で #3C3C3C、後の2色で #FFFFFF） |
| マーカー | #F9DC72（黄。区別が要る2つ目だけ #9ADB6E） |
| ハイライト | #E5B521（マトリクスの星など、注目する1点だけ） |
| 図の矢印・引き出し線 | #A3A5A8 |
| 図の淡い面 | #EEEEEC（マトリクスの象限など） |
| 比較の他社列 | #8A94A6 |

- グラデーション背景、影、グロー、絵文字は使わない（マーカーと下の「グラデーションを指示されたとき」は例外）
- 本文をアクセント色にするのは、短い語か大きな数字だけ
- 文字と背景のコントラストは本文4.5:1以上、44px以上は3:1以上。アクセントが明るすぎて白文字が読めないときは、箱の文字を #3C3C3C にする

### グラデーションを指示されたとき

「グラデーションを使って」と言われたときだけ、次の2種類に限って使う。

- **文字のグラデ（工程名）**：淡いグレーの矢羽（#F7F8FA から #ECEEF0 へ）を並べ、各矢羽の工程名を太字48〜56pxのグラデ文字にする。色は矢羽ごとに少しずつずらし、左から右へ一続きに流れるようにする。説明文は単色
- **棒のグラデ（比較・割合）**：強調したい棒だけを横方向に淡いアクセントから A へのグラデにし、比較対象は #D9D9D9 の単色。棒の角は丸めず、値は棒の右に太字で
- どちらも1スライドに1か所。グラデを使うスライドではマーカーを使わない

## 書体

- 指定がなければ、欧文と数字は Montserrat、和文は Noto Sans JP。指定は `font-family: 'Montserrat', 'Noto Sans JP', Arial, sans-serif` の順にする（Montserrat に和文の字形がないため）。読み込むウェイトは500・600・700・900
- ウェイト：見出し・強調700、本文500。400以下の細字は使わない
- 締めの一文（そのページの結論を言い切る一文）は900、44px前後で、アクセント色で置いてよい
- サイズ：ページタイトル44、リード文36〜40、箱の見出し32、本文24〜28、注記24、大きな数字240〜300。24px未満の文字は使わない。ptで指定する形式（pptx・Googleスライド・Canva）では、ページを16:9ワイドに設定したうえで px の半分を pt にする（44px→22pt、24px→12pt、240px→120pt）
- 数字は太字で一回り大きくし、「万円」「%」などの単位は小さく添える
- 大文字英字の飾りラベル（OUR SERVICE、PROBLEM など）を見出しの上に置かない。小文字の「point 1」「Case 01」程度はよい

## ページの骨組み（全スライド共通）

1. 左上：アクセント色の縦バー（幅8px、高さ48px）＋ページタイトル44px/700。タイトルの下に全幅のヘアライン（#E6E4DE、1px）
2. 右上：ロゴを小さく（高さ32px程度）。ロゴがなければ空ける
3. タイトルの下：リード文を1〜2行、中央揃え36〜40px/700。言いたいことはここで言う
4. その下：図・イラスト・数字のどれか1つを主役に置く
5. 右下：ページ番号24px、弱テキスト色

## ページタイトル

- 句読点（「、」「。」）を使わずに済む一言にする。主張はリード文に回す
- 良い：「サービスの特徴」「料金のご案内」「導入までの流れ」「導入後の体制」「導入事例」
- 悪い：「顧客の手元から、煩雑な作業をなくす」のような句読点入りの主張文
- 全角14字まで。疑問形は「こんなお悩みありませんか？」のような1枚だけ

## 余白

**左詰めにしない**
- 主要な中身は幅1440px以内で中央に置き、左右240px以上の余白を残す
- 箱・表・カードの中の文字は、枠から最低32px離す。色の帯や縦線の横に置く文字は64px以上離す
- リード文と見出しは中央揃え。左揃えは2カラムの説明文や表の中身だけ
- 上下の間隔は24 / 40 / 64px の3段階

**余白を余らせすぎない**
- リード文の下からページ番号の上まで（y 約300〜940、幅1440px）を主役の領域とし、その縦横8割以上を中身で埋める。要素の間が120pxを超えたら配置かサイズを見直す
- 主役は大きく。大きな数字は240〜300px、主役のイラストは高さ480px以上、図は幅1440pxいっぱいを目安に
- 2カラムは左右の幅を使い切り、間に空白の帯を作らない
- 補足の図や注記は主役のすぐ下か横に置き、画面の下端に孤立させない
- 仕上げに全スライドを縮小して見て、余白が中身より目立つページを作り直す

## 強調の手法

**太線マーカー**：キーワードの下半分に太い黄色の線を敷く。1スライドに1〜2か所。CSSなら `background: linear-gradient(180deg, transparent 52%, #F9DC72 52%)`。部分的な文字に背景を付けられない環境では、その語だけを独立した段落にして横並びにする

**アクセントのラウンド箱（ピル）**：短い語を白抜き文字で、角丸の強いアクセントの箱に入れる。角丸は高さの半分、左右padding 40px以上、全角10字まで。カード上端の「point 1」、図のノード、強調したい短い条件、段階名に使う

マーカーとピルは合わせて1スライド3つまで（ポイントカードや図のノードとして使うピルは除く）。

## 線の太さ

図形を囲む線が細いと弱く、AIが作ったように見える。箱・カード・列の枠、番号の円、ハブ図の円は6〜9px（5〜7pt）。矢印は5〜6pxで矢じりを大きく。1〜3pxの細い線は、表の罫線とタイトル下のヘアラインだけに使う。

## 要点を複数並べるとき

「・」の箇条書きは使わず、番号を円で囲んだリストにする。目次、課題、選ばれる理由など、2〜5個並ぶときはすべてこの形。

- 番号：直径120pxの円、線6pxのアクセント、塗りなし。中に「01」「02」を太字36px、アクセント色。必ず2桁
- 本文：円の右に80px空け、44px/700。各項目1行、全角28字まで
- 項目の間は48〜64px。リスト全体をひとかたまりとして中央に置き、文字の頭は左揃え
- 項目は問いかけや「」を使った具体的な一文にする。単語だけを並べない

## 図解（言葉より図で伝える）

箇条書きにする前に、図にできないかを考える。資料の半分以上のスライドに図解を入れる。

1. **アイコン付きの工程フロー**（手順・工程の第一候補）：工程を3〜5個横に並べ、「段階色」で左から右へ濃くする。各工程に工程名（全角6字まで）、アイコン（140〜180px）、説明2行まで
2. **業務フロー図**：白い角丸箱（角丸24px、太枠）を順に並べ、太い矢印でつなぐ。箱の中に作業名と、使うツールのロゴ
3. **ハブ図**：中央にイラスト、周りにピルで領域を円形に置き、淡いアクセントの矢印を中央へ。主役の領域の縦8割以上を使う
4. **ピラミッド（段階）**：段階的に何かを表すときはこの図を使う。三角形を水平に3〜5段に切り、段の間に白い細い隙間を空ける。色は上ほど濃く下ほど淡い段階色。各段の右端から丸い点付きの水平な引き出し線（#A3A5A8、太さ4px）を右へ伸ばし、その先に段階名（32px/700）と説明を置く。文字を三角形の上に重ねない
5. **比較図**：「今のやり方」と「導入後」を左右に並べ、導入後の見出しだけアクセント
6. **比較表**：列はサービス、行は比較項目。左端に分類の列を置き、同じ分類の行をまとめる。セルは「○」「△」「×」と短い理由。見出し行は他社列をグレー地、自社列をアクセント地に白文字。セルは自社列だけアクセントの地。罫線は引かず白い細い隙間で区切る。他社名は頭文字で伏せるのを基本にする
7. **ポイントカード**：白い角丸カード3〜4枚。カードの上端から40px前後の余白を取って「point 1」のピルを置き、ピルを枠線に貼りつけない。中にイラスト、見出し（全角8字まで）、説明2行
8. **タイムライン**：段階名を横に並べ、下にイラストと説明
9. **大きな数字**：数字だけを大きく、単位を小さく、下に黄色マーカー。時点を必ず添える
10. **マトリクス**：2軸で位置づけを見せるときはこの図を使う。淡いグレー（#EEEEEC）の角丸の象限を4つ並べ、その間を両端矢印の十字（#A3A5A8、太さ5px）で区切る。軸名は矢印の4つの端の外側に置く。注目させたい位置にハイライト色の星を1つだけ置き、象限の中には象限名と短い説明を入れる
11. **ベン図**：集合の重なりは、半透明の円を2〜3個重ねて、重なったところが濃く見えるようにする。全体と部分の関係は、大きな淡い円の中に濃い小さな円を置く。円の色は段階色から選び、枠線は付けない。集合名は色の丸を添えた凡例にして図の下に置き、円の上に文字を重ねない

図の中の文字は24px以上。矢印は向きをそろえ、交差させない。

### アイコン

- 2トーンの太線アイコンをSVGで描く。viewBox 0 0 160 160、線幅6px、角と端は丸める。外形は #3C3C3C、内側は白塗り、細部だけアクセント色。白塗りがあるので、濃い色の上でも沈まない
- モチーフはその資料の題材にある実際の物（書類、PC、カレンダー、吹き出し、箱、道具など）。一つのアイコンに描く物は1つ。資料内の全アイコンで線幅と色を統一する
- 絵文字、影、グラデは使わない。アイコンは「物」、イラストは「人と場面」と使い分ける

## イラストと写真

- イラストを多用する。表紙・目次・章扉には必ず入れ、本文でも図解のないスライドには大きなイラストを主役として置く
- テイストは、斜め上から見たアイソメトリックのフラットなビジネスイラスト。スーツ姿の人物、オフィスの机、PC、グラフ、書類、ビルなどを、紺・グレー・淡い青・黄色を中心にした配色で描いたもの。資料の中でこのテイストを統一し、写真や別の画風を混ぜない
- 画像生成を使うときは、プロンプトの型をそろえて主題だけ入れ替える（「Isometric flat business illustration on a plain white background: ［主題。人物は navy suit］. Clean flat vector style with soft shading, palette of navy, gray, light blue and yellow accents, no text, no logo.」）。一枚に描く場面は1つ。生成した絵は、白い背景を透過して資料の背景になじませる
- 引用する素材は、商用可でクレジット条件を満たせるものだけ。出典と利用条件を報告する
- SVGで人物を描いて代用しない。用意できないときはサイズを決めた空の枠を置き、必要な絵の内容を報告する
- 光る球、ロボット、回路、握手のストック写真、抽象的な3Dは使わない
- 大きいイラストは1スライド1点、小さいイラストは同じ大きさで揃える。枠や影を付けない
- 人物写真は、本人から渡されたものだけを使う。正方形か円に切り抜き、顔が切れないようにして、近くに役職と氏名を添える。複数人は同じサイズに揃える

## 数字とグラフ

- 数字や実績を新たに作らない。渡されていない数字は [00] のような空欄にし、報告で一覧にする
- 人の言葉を引用するときは原文どおりにし、言い換えには「」を付けない
- 数字には「何の数字か」「いつ時点か」「何との比較か」を添える
- グラフは渡された画像かデータをそのまま使う。画像から値を読み取って描き直したり、推測したりしない
- 見出しの数字とグラフの値が食い違っていたら、直さずに報告する

## 出力先と崩れない書き出し

色・余白・図解・コピーのルールは形式が変わっても同じ。変わるのは組み方だけ。HTMLで作ってから別形式へ書き出すと崩れる前提でいる。崩したくない形式は、はじめからその形式のネイティブな部品で組み、HTMLを経由しない。

### 寸法をそろえる

どのツールでもページを16:9のワイド（13.333in × 7.5in ＝ 33.87cm × 19.05cm、Canvaなら1920×1080px）に設定する。こうすると1920×1080pxの設計が実寸とそのまま対応し（144dpi）、pxをptに直すときは半分にすればいい。位置はpxの絶対値で覚えず「スライド幅に対する割合」で置く。左右の余白は各12.5%、主役の領域は幅75%、という具合にそろえる。

### フォント（崩れの最大の原因）

和文が置き換わって文字幅が変わると、折り返しと配置が総崩れになる。ここを外すと他が全部ずれる。

- **PowerPoint**：Noto Sans JP と Montserrat をファイルに埋め込む（ファイル＞オプション＞保存＞フォントの埋め込み）。埋め込まない運用なら、游ゴシック・ヒラギノ・メイリオ、欧文はArialへ置き換わる前提で、箱に1割以上の余裕を取る。和文のウェイト900は太字＋サイズで代用する
- **Googleスライド**：Noto Sans JP も Montserrat も Google フォントにあるので、選べばそのまま出る。和文に900がないので、締めの一文は700とサイズで効かせる
- **Canva**：どちらもある。ブランドキットに登録しておくと速い
- **共通**：文字は図形の上に座標で重ねない。箱＝テキスト枠として枠に流し込み、フォントが伸びても枠内で折り返す。社名・カタカナ語・数字と単位は改行禁止にする

### 図形はネイティブ、絵は画像

箱・円・角丸のピル・矢印・工程フローの帯・マトリクスの枠・比較表のように、図形で表せるものは各ツールのネイティブ図形で組む。線の太さ6〜9pxは3〜4.5ptに直す。角丸・枠線・塗りは図形のプロパティで付ける。こうすれば拡大しても滲まず、受け取った人が編集もできる。

人物や場面のイラストと、細かい2トーンのアイコンは、画像として貼る。SVGはツールによって崩れ、とくに文字入りSVGをpptxに入れると危ない。透過PNGで統一する。解像度は使う大きさの2倍以上にする（主役イラストなら長辺1000px以上、アイコンなら320px以上）。Canvaはアップロード、Googleスライドとpptxは画像の挿入で貼る。python-pptxで組むならPNGを貼る。

### HTML固有の仕掛けの置き換え

- **黄色マーカー**：CSSの`linear-gradient`は文字には移植できない。各ツールでは文字のハイライト（蛍光ペン）機能を使うか、その語だけ別のテキスト枠にして背後に黄色の帯を文字の下半分に敷く。1スライド1〜2か所は変えない
- **矢印・コネクタ**：座標で箱のあいだに線を引かない。ツールのコネクタ（図形と図形をつなぐ線）でつなぐと、要素を動かしても追従する。むずければ要素を等間隔に並べ、あいだに矢印の図形を置く
- **文字グラデ**：ツール間で再現しにくい。崩したくない運用では、グラデを指示されても単色と太さ・サイズで差をつけるか、帯状の図形の塗りのグラデに留める

### 出す前に実物で確認

作ったら必ずその形式で一度書き出して目で見る。pptxはPDFか画像にして、Googleスライドはダウンロードのプレビュー、Canvaはプレビューで、フォントの置き換わり・はみ出し・改行位置・図形のずれを確認して直す。見せるだけで編集が要らないなら、PDF書き出しが一番崩れない。

## 改行

- 文や語の途中で行が変わる状態を残さない（悪い例：「ほとん／どない」「スタートアッ／プ向け」）
- 2行になる文は、句読点か意味の切れ目に改行を入れて、改行位置を自分で決める
- 箱に入れる文は、1行に入る文字数（内側の幅÷文字サイズ。英数字は0.6文字）を先に数え、入らなければ改行・箱を広げる・文を短くする
- 社名・サービス名・カタカナ語・数字と単位は2行に割らない

## コピー

- スライドに載せる文は、です・ます調にしない。言い切り（〜する／〜できる／〜している）か体言止めで終え、体言止めばかり続かないように混ぜる。引用は原文のまま、スピーカーノートは話し言葉でよい
  - 悪い例：「設計から運用まで引き受けるサービスです」「2.4ヶ月で回収できています」
  - 良い例：「設計から運用まで引き受けるサービス」「2.4ヶ月で回収できている」
- 「シームレス」「加速」「革新的」「DX推進で業務効率化」のような中身のない言い回しを避け、何を・誰の代わりに・どこまでやるかを書く
- 感嘆符は表紙のキャッチに限る。見出しと本文には使わない

## テンプレートを作るとき

- テキストは「ページタイトル」「ここにリード文が入ります」のような、何が入るかわかるダミー文にする。実在の社名・人名・数字は入れない
- 数字は「00」「00.0%」、連絡先は sample@example.com と https://example.com/
- 画像は淡いグレー（#EDEBE6）の地に画像マークを描いたダミー、人物の枠は人型のダミー、アイコンは汎用のダミーにする。イラストを多用する前提で、表紙・目次・章扉・本文にダミー画像の枠を大きく取っておく
- 各スライドのノート欄に、その型の使い方とダミーを何に差し替えるかを書く

## やらないこと

- タイトルに「、」「。」を入れた長い主張文
- 文字を画面の左端や枠線に寄せること
- アイコン付きの均等3カラムに説明文を並べるだけのスライド
- 「・」の箇条書きで要点を並べること
- 文字だけの図、細い枠線
- グラデ背景、影、グロー、絵文字、自作のSVG人物
- 小さな要素が中央に固まり、まわりががらんとしたページ
- 会社名を入れ替えても成り立つ言い回し。仕上げに「これはこの会社にしか言えないか」を確かめる
