# natural-slides

AIが作る日本語スライドにありがちな「細い線・余白だらけ・均等3カラム・箇条書きの羅列・ですます調の説明文」を避けるための、Claude 向けスキル。図とイラスト、太い線、言い切る文で、人が手で作ったように見える資料を作る。営業資料、提案書、会社紹介、サービス説明、セミナー資料、テンプレートを想定している。

特定の会社や業種に縛られないよう作ってある。メインカラー1色・ロゴ・社名を「ブランド設定」で差し替えれば、そのまま自分の資料に使える。色や線の太さ、図解の型（工程フロー、ピラミッド、マトリクス、ベン図など）、余白の取り方まで具体的な数値で指示しているのが中身の大半。

## 何をするスキルか

Claude にスライドを作らせると、どうしても「それっぽいけど中身の薄い」仕上がりになりやすい。このスキルは、その「AIっぽさ」の出どころを一つずつ潰していく。たとえば枠線は6〜9pxと太くする、要点は「・」ではなく円で囲んだ番号で並べる、段階を見せるときはピラミッド図を使う、タイトルに句読点を入れない、本文をです・ます調にしない、といった具合に、判断に迷いやすいところを数値とルールで固定する。

見出しの下に灰色の小さな説明を添える組み方も、AIっぽさが出やすいところなので控える。カードや図の段に置く文字は見出しか一文の1つにし、断り書きはスピーカーノートに回す。小さく薄い文字は、出典や数字の時点のように、ないと困るところにだけ使う。背景は真っ白（#FFFFFF）にし、カードや図の箱は背景と同じ白のまま、太い枠線で区切る。

出力形式を指定しなければ、その環境で使えるスライドの仕組み（スライド型のアーティファクト、`.pptx`、HTML など）で作る。比率は16:9、1920×1080基準。

PowerPoint・Canva・Googleスライドに持っていっても崩れにくいよう、組み方も決めてある。文字は見出しと段落の2種類だけで書き、円は図形、矢印はコネクタとして置く。ピルは幅と高さを数値で決めた箱の中に文字を置き、マーカーは独立した一行にする。書き出したあとでも、文字の打ち替えや図形の移動ができる。見せるだけで編集しないなら PDF が一番崩れない。詳しくは SKILL.md の「書き出しやすい構成」にある。

Claude のスライド型アーティファクトで作った場合、共有メニューの「エクスポート」から PDF・PowerPoint・PNG で書き出せ、「送信先」の Google Slides を選ぶと Google ドライブに編集できるコピーができる。Canva は送信先に出てこないので、PowerPoint を「現在のフォント」で書き出し、Canva のホームの「アップロード」から取り込む。取り込むと、そのまま編集できるプレゼンテーションになる。書き出すたびに新しいファイルができるので、資料を直したあとは書き出し直し、古いものは消しておく。

## 使い方

Claude Code や Claude のスキル対応環境で、`skills/natural-slides/SKILL.md` を読み込める場所に置く。

### Claude のチャット（claude.ai・デスクトップアプリ）で使う

いちばん手軽なのは、チャットでこのリポジトリのリンクを渡して頼む方法。設定の「機能」で「クラウドでコードを実行」と「外部ネットワークへの通信を許可」をオンにしてから、新しいチャットで次のように送る。

```text
https://github.com/yoshitakagiii/natural-slides のスキルを使えるようにして
```

Claude がリポジトリを取ってきて「Skills を保存」のカードを出すので、「保存」を押せば入る。このやり方で保存されるのは SKILL.md 1ファイルで、brand.example.md の中身は SKILL.md の中に入る。新しい版にするときは「natural-slides を GitHub の最新版にして」と頼む。

うまくいかないときは、zip をアップロードする。`skills/natural-slides` フォルダを丸ごと zip にする。zip の中身は `natural-slides/SKILL.md` と `natural-slides/brand.example.md` の形になっていればいい。

```bash
git clone https://github.com/yoshitakagiii/natural-slides.git
cd natural-slides/skills && zip -r ../../natural-slides.zip natural-slides
```

「設定」の「Skills」を開き、「Skills を追加」→「Skills をアップロード」で zip を選ぶ。新しい版に入れ替えるときは、一覧で natural-slides を開き、右上の「…」から「置き換え」を選んで zip を選ぶ。入れ替えるたびに版の番号（v1、v2…）が上がる。

### Claude Code で使う

Claude Code にも、チャットと同じ1行（「https://github.com/yoshitakagiii/natural-slides のスキルを使えるようにして」）を送れば、Claude がリポジトリを取ってきて `~/.claude/skills/` に入れる。自分で入れるなら、ユーザー全体のスキルとして使う場合は、このリポジトリを clone して中の `skills/natural-slides` を `~/.claude/skills/` にコピーする。

```bash
git clone https://github.com/yoshitakagiii/natural-slides.git
cp -r natural-slides/skills/natural-slides ~/.claude/skills/
```

プロジェクト単位で使うなら、同じものをそのリポジトリの `.claude/skills/` 以下に置く。

置いたあとは「このサービスの営業資料を作って」「提案書のテンプレートを作って」のように頼めば、スキルの説明文にある条件に合ったときに Claude が自動で読み込む。明示的に呼びたいときは `/natural-slides` のように指定する環境もある。

## 最初に使うとき

初めて資料を頼むと、Claude は作り始める前に、いまの既定値を見せてブランド設定を一度だけ尋ねる。尋ねるのはメインカラー、書体、ロゴ、会社名・サービス名、主な出力先（PDF・PowerPoint・Googleスライド・Canva）の5つ。「このままでいい」と答えれば、既定値（メインカラー #2F3237、Montserrat ＋ Noto Sans JP）で作る。

決まった設定は、Claude Code ならスキルのフォルダに `brand.md` として保存され、次からは尋ねずにその設定で作る。Claude のチャットのようにスキルのフォルダに書き込めない環境では、Claude が設定の中身を渡すので、プロジェクトの指示に貼っておく。

質問を飛ばしたいなら、先に `skills/natural-slides/brand.example.md` を `brand.md` という名前でコピーし、値を書き換えておけばいい。

## イラストと Canva

Canva のアカウントを持ち、Canva のコネクタを Claude につないでいれば、表紙や章扉、図のないページに、斜め上から見たフラットなビジネスイラストが入る。Claude がイラストを生成し、原寸の PNG で受け取って資料に入れるところまで自動で進める。作業用に「natural-slides 画像書き出し用」というデザインが Canva に1つ作られるが、資料ができたら消してかまわない。

Canva がなくても、資料は欠けずにできあがる。その場合、Claude ははじめからイラストを使わない組み方で作る。主役は図解と大きな数字で、表紙はメインカラーの面と大きなタイトル、章扉は大きな章番号、図のないページは大きなアイコンか大きく置いた一文で組む。空の枠や「ここに絵を入れる」という置き場は残らない。自分で用意した絵を渡せば、それを使って作る。

Claude のチャットで Canva を使う場合は、Claude が画像を取り込むときに `export-download.canva.com` へつながる必要がある。つながらないと言われたら、「設定」の「機能」で「外部ネットワークへの通信を許可」をオンにし、その下の「ドメイン許可リスト」にこのドメインを足す。足せないときは、イラストを使わない組み方に切り替わる。

## 文章の自然さを上げたいとき

スライドに載せる文の自然さをさらに詰めたいときは、日本語の文章スキルと併用するとよい。相性がいいのは [coji/natural-japanese](https://github.com/coji/natural-japanese)（MIT）。natural-slides 単体でも動くので、必須ではない。
